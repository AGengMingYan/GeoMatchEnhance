# 参数手册（创建模板 / 模板匹配）

> 这是唯一一份讲**参数数值语义**的文档：每个参数的默认值、取值范围、含义、
> 以及"什么情况下才需要改它"。
> 界面上的位置与操作见 [GeoGUIDemo使用说明.md](GeoGUIDemo使用说明.md)，
> API 签名见 [SDK.md](SDK.md)，与 Halcon 的对应关系见 [与Halcon差距清单.md](与Halcon差距清单.md)。
>
> **一句话原则**：先把 `contrast`/`minContrast` 调对（决定"选的点对不对"），
> 再调速度和层数；分数类闸门（`minScore`/`minCoverage`）最后调。

---

## 0. 先分清两类参数

| 类别 | 改了会怎样 | 典型成员 |
|---|---|---|
| **建模参数** | 必须**重建模型**（`.shm` 里存的是已经选好的点集） | `contrast` / `minContrast` / `maxPoints` / `minSide` / `minChainLen` / `mask` / 角度·尺度范围 / `optimization` |
| **搜索参数** | 只影响本次搜索，**同一个模型可随时切换** | `minScore` / `maxMatches` / `maxOverlap` / `greediness` / `subpixel` / `metric` / 搜索层数与子范围 / `timeoutMs` |

在 CLI 里前者是 `-contrast/-hi/-points/-chain/-min-side/-levels/-bands/-optimization`，
后者是 `-minscore/-max/-max-overlap/-greediness/-subpix/-metric/-find-levels/-find-angle*/-timeout`。
在 GUI 里前者在「② 模板参数」，后者在「③ 搜索参数」（这是刻意的分组，见 §6）。

---

## 1. 建模参数 · 形状匹配（`MatchParams`）

### 1.1 边缘提取（决定"哪些点进入模型"）

| 参数 | CLI | 默认 | 取值范围 | 含义 | 什么时候改 |
|---|---|---|---|---|---|
| `minContrast` | `-contrast` | **12** | 1 ~ 255（Sobel 幅值） | **滞后低阈值**：种子边周围比它强的边会被"长"回来 | **最先调这个。** 目标边缘模糊/低对比→调小；背景噪点多→调大 |
| `contrast` | `-hi` | **30** | ≥ `minContrast` | **滞后高阈值**：必须达到它才成为种子 | 锐边目标调大（data1 焊盘 120/160 时均分 0.679 → **0.961**）；低对比 U 弯在 120/160 下**建不出模型**，要用默认 |
| `maxPoints` | `-points` | **1200** | 0 ~ 任意；0 = 不限 | 最细层保留多少个模型点 | 大模板/密集纹理不够用就加大；**0 只适合离线建模**（粗层点数暴涨，refine 7.2→28.6 ms） |
| `minChainLen` | `-chain` | **2** | 2 ~ 8（上限 8） | 丢弃短于 N 像素的孤立边缘链 | **散斑/砂面模板**：`2` 时散斑抢走 79% 点数预算 → 分数 0.511；调到 `8` → **0.708**。判据不是模板尺寸，而是 `maxPoints/链数`（≥8→2、4~8→4、2~4→6、<2→8） |
| `mask` | `-mask` | 空 | CV_8U 图，非零=参与 | 只有掩码内区域能产生模型点 | 模板里有会动的结构（丝印、反光、料号）时 |
| `contrastBands` | `-bands` | 空 | `lo1,hi1[,lo2,hi2...]` | **多段幅值区间**（Halcon 元组语义）：只取落在任意段内的边 | "只要中等边、丢掉高光强边"。实测 case1：单段 0.983 / `12,60` 0.805 / `0,40,120,400` 0.599 |
| `optimization` | `-optimization` | 空 | `none`/`auto`/`point_reduction_low|medium|high` | **只为 Halcon 配方迁移**，映射到 `maxPoints`（×1/×1/0.75/0.50/0.33） | 一般不用；要精确控点直接用 `maxPoints` |

> 单位提醒：CLI/GUI 上的"灰度差"×4 = 内部 Sobel 幅值。GUI 里显示的是灰度差，
> 所以"GUI 30" ↔ "CLI 120"。两者不可直接抄数字。

### 1.2 旋转 / 尺度范围（决定"模型有多大"）

| 参数 | CLI | 默认 | 含义 | 什么时候改 |
|---|---|---|---|---|
| `angleStart` | `-angle-start` | **-π（-180°）** | 起始角（弧度） | 工件有固定朝向时收窄 |
| `angleExtent` | `-angle` | **2π（360°）** | 角度范围宽度 | **能收窄就收窄**：角度数是线性成本。data1 全在 ±1.1° → `-angle 20` 就够 |
| `angleStep` | `-angle-step` | **0 = 自动** | 角度步长（其中 0 = 按模板半径取 0.5°~5°） | 一般不用；要复刻别人的网格才填 |
| `scaleMin` / `scaleMax` | `-smin/-smax` | **1.0 / 1.0** | 尺度范围（放 1.0/1.0 = 不搜尺度，最快） | 有缩放才开；**范围越宽越慢**（140px 模板/1280×1024：单尺度 5 ms、0.2~2 → 31 ms、0.2~4 → 48 ms） |
| `scaleStep` | — | **0 = 自动** | 尺度步长 | 一般不用 |

### 1.3 金字塔（同时决定"模型多深"和"能搜多快"）

| 参数 | CLI | 默认 | 含义 | 什么时候改 |
|---|---|---|---|---|
| `numLevels` | `-levels` | **0 = 自动** | 建模层数**上限** | **不要填 1**：1 层 = 全分辨率暴力搜索，比 3 层慢约 130 倍，结果完全相同 |
| `minSide` | `-min-side` | **24** | 最粗一层最短边下限（像素），即"模型能建多深" | **大图提速第一开关**。经验规则：想要 N 层需 `minSide <= 模板短边 / 2^(N-1)`（110px 要 ≤13、101px 要 ≤12、140/154px 要 ≤16）。实测 qfn1 48.0 → **8.3 ms**（`-min-side 12`）。**代价**：层越粗弱目标越容易被糊掉 —— `16` 全数据集零回归，`12` 在 data2 丢 1 个 0.654 的弱目标 |

## 2. 建模参数 · NCC（`NccParams`）

| 参数 | 默认 | 含义 | 备注 |
|---|---|---|---|
| `numLevels` | **0 = 自动** | 建模层数 | 最粗层封顶到短边 ≥9 px（与 Halcon 一致，Halcon 封顶 15×15） |
| `angleStart` / `angleExtent` | **-180° / 360°** | 旋转范围 | 360° 要把画布放大到对角线，**已知角度就收窄**（case1 360°→20° 的搜索 14.4→10.2 ms） |
| `angleStep` | **0 = 自动（1°@level0）** | 角度步长 | — |
| `metric` | **0** | `0` = use_polarity（明暗必须一致）<br>`1` = ignore_global_polarity（允许整体反相） | **NCC 的极性是建模参数**（改了要重建）；Shape 的极性是搜索参数（不用重建） |
| `mask` | 空 | 非零 = 参与相关 | NCC 有掩码，Halcon 的 `create_ncc_model` 没有 |

> NCC **没有尺度维度**（Halcon 也没有）。80 张缩放样本只检出 61/80，需要尺度就用形状匹配。

## 3. 搜索参数 · 形状匹配（`FindParams`）

### 3.1 判据（决定"报不报"）

| 参数 | CLI | 默认 | 取值范围 | 含义 | 什么时候改 |
|---|---|---|---|---|---|
| `minScore` | `-minscore` | **0.7**（库）/ 0.5（CLI 示例） | 0 ~ 1 | 最低分数。默认口径是 `mean`（与 Halcon 一致） | 追召回才调低，**但同时要开 `minCoverage`**，否则相似结构会一起进来 |
| `minCoverage` | `-min-cover` | **0 = 关** | 0 ~ 1 | 覆盖率 = 方向一致的模型点占比。分母**永远是全部模型点** | 重复纹理/多结构场景**先开这个（0.80~0.85）**，比调 NMS 有效。实测 case1 真值 0.99 / 误检 0.62 |
| `cellMissMax` | `-cell-miss` | **0.35** | 0 ~ 1 | 模板 4×4 格中"图像上几乎没梯度"的格占比上限，超过即拒 | 拒掉"只对上模板一部分"的错位实例。`0.30` 太紧（真目标实测到 0.25） |
| `scoreMode` | `-score-mode` | **0** | 0/1/2/3 | `0`=mean（Halcon 口径）`2`=trimmed-mean `1`=positive-mean `3`=clipped-mean | **不要把 `1` 当默认**：错位置的假位姿在 mode1 下能到 0.946（Halcon 同位置 0.556） |
| `skipWeight` | `-skip-w` | **0 = 关** | 0 ~ 1 | >0 时把"图像梯度弱于点"的模型点从分子分母一起去掉 | 模糊帧分数 +0.1~0.3，但"只对上模板一部分"的位姿会被抬到 0.82+。**只追召回时用** |
| `metric` | `-metric` | **0** | 0/1/2 | `0` use_polarity `1` ignore_global_polarity `2` ignore_local_polarity | 目标明暗反转/局部反光。`1` 约慢 2×，`2` 走标量扫描，**慢数倍** |
| `subpixel` | `-subpix` | **1** | 0/1/2 | `0` 关 / `1` 抛物线插值 / `2` 高斯-牛顿最小二乘 | 高精度测量、软边用 `2`（更准、稍慢） |

### 3.2 结果数量与去重

| 参数 | CLI | 默认 | 含义 | 什么时候改 |
|---|---|---|---|---|
| `maxMatches` | `-max` | **20** | 最多返回几个实例 | 多实例场景调大 |
| `maxOverlap` | `-max-overlap` | **1.0 = 关** | 两实例的模型框重叠超过该比例只留高分（交集/较小框面积，与尺寸无关） | **推荐用它代替 `minDistance`**。Halcon 默认 0.5 |
| `minDistance` | `-min-dist` | **40** | 两实例中心最小像素距离（旧口径，与模板尺寸挂钩） | 只在要用旧阈值时。两项同时生效，取更严 |

### 3.3 速度

| 参数 | CLI | 默认 | 含义 | 什么时候改 |
|---|---|---|---|---|
| `greediness` | `-greediness` | **0.9** | 贪心度，越大越快越可能漏 | 0.9~0.95；**不要为速度先动它**，先动层数 |
| `numLevels` | `-find-levels` | **0 = 模型全部层** | 搜索最多用模型几层（从最细层数起） | 已知目标清晰→用更粗层（快）；弱目标→调小到更细层（稳）。**不需要重建模型**。<br>实测 4 层模型 `2/3/4` = 450 / 44.9 / **8.3 ms** |
| `angleStart` / `angleExtent` | `-find-angle` / `-find-angle-extent` | **0 / -1（= 用模型全部角度）** | **搜索期**角度子范围（Halcon 同名语义），可跨 ±180 | 已知工件最大偏转就设，**不用重建模型**。实测 qfn1 9.80 → ±10° **5.00 ms** |
| `scaleMin` / `scaleMax` | `-find-smin` / `-find-smax` | **0 / 0（= 用模型全部尺度）** | **搜索期**尺度子范围 | 同上 |
| `timeoutMs` | `-timeout` | **0 = 不限** | 超时毫秒。超时**返回已找到的结果**（不报错），`lastSearchTimedOut()` 告知不完整 | 产线要保节拍时必设。粒度 = 一个粗扫位姿（几 ms） |
| `useOpenCL` | `-ocl` | **true** | 是否尝试 GPU 预处理 | 很多机器只有集显、收益为负，测过再决定 |
| `debug` | `-debug` | **0** | 1 = 打印结果，2 = 打印相位耗时 | **对外报速度别开 2**（额外 `minMaxSerial`，慢 20~35%） |

## 4. 搜索参数 · NCC（`NccFindParams`）

| 参数 | CLI | 默认 | 含义 | 什么时候改 |
|---|---|---|---|---|
| `minScore` | `-minscore` | **0.7** | NCC 分数 `[-1,1]` | **NCC 负样本 top-1 就落在 0.65~0.72**，真阳性 ≥0.98 ⇒ 阈值建议 **0.85~0.90**，不能沿用 0.7 |
| `maxMatches` | `-max` | **1** | 最多返回几个 | 多实例调大 |
| `maxOverlap` | `-overlap` | **0.5** | 重叠上限 | 与 Halcon NCC 默认一致 |
| `subpixel` | `-subpix` | **1** | `0` 关 / `1` 抛物线 | Halcon NCC 只接受 `true/false`，已对齐 |
| `numLevels` | `-levels` | **0 = 模型全部层** | 从哪层开始粗扫 | 不必重建模型 |
| `angleStart` / `angleExtent` | `-find-angle` / `-find-angle-extent` | **0 / -1** | **搜索期**角度子范围 | 实测 case1 14.39 → ±10° **10.18 ms** |
| `timeoutMs` | `-timeout` | **0** | 超时毫秒 | 同上 |

> NCC 的**局限**：范围窄于该层角度步长（1°×2^level，3 层即 16°）时，取离范围中心
> 最近的粗角度，剩余误差由 refine 收敛 —— 不是 bug，是粗层网格的必然现象。

## 5. 调参顺序（按这个顺序，别跳）

1. **建不出模型？** 先降 `contrast`/`minContrast`（低对比）或提高 `maxPoints`（大模板）。
2. **分数总是 0.5~0.7 上不去？** 先怀疑对比度档位（§1.1），再怀疑散斑抢预算（`minChainLen`）。
3. **太慢？** 按收益排序：`minSide`（多一层 ≈ 4× 少位置）→ 收窄角度/尺度范围 →
   搜索期子范围（`-find-angle*`）→ `greediness`。**最后才考虑 `maxPoints`**（影响精度）。
4. **有假目标？** 先开 `minCoverage`，再看 `cellMissMax`，最后才动 `maxOverlap`。
5. **两个"层数"别搞混**（见下）。

## 6. 三个"层数"别搞混（最容易踩）

| 参数 | 类别 | 作用 | 改了要不要重建 |
|---|---|---|---|
| `MatchParams::numLevels` | 建模 | 最多建几层（上限） | 要 |
| `MatchParams::minSide` | 建模 | 最粗层最短边（决定实际能建多深） | 要 |
| `FindParams::numLevels` | 搜索 | 本次从哪层开始粗扫 | **不要** |

NCC 同理：`NccParams::numLevels`（建模）/ `NccFindParams::numLevels`（搜索）。
**"改小 `minSide` 却没变快"通常是因为没跨过整除边界**，不是参数没用。

## 7. 参数 → CLI / GUI 对照

| 参数 | CLI | GUI 位置 |
|---|---|---|
| `contrast` / `minContrast` | `-hi` / `-contrast` | ② 模板参数 → 特征提取 |
| `maxPoints` / `minChainLen` | `-points` / `-chain` | ② 特征提取（`minChainLen` 仅 CLI） |
| `minSide` / `numLevels`（建模） | `-min-side` / `-levels` | ② 金字塔结构 |
| 角度/尺度范围 | `-angle-start` / `-angle` / `-smin` / `-smax` | ② 旋转与缩放 |
| `minScore` | `-minscore` | ① 匹配 → 3. 搜索参数 |
| `minCoverage` / `skipWeight` / `cellMissMax` / `scoreMode` / `metric` | `-min-cover` / `-skip-w` / `-cell-miss` / `-score-mode` / `-metric` | ① 匹配 → 匹配判据 |
| `maxMatches` / `maxOverlap` / `minDistance` | `-max` / `-max-overlap` / `-min-dist` | ③ 结果筛选 |
| `numLevels`（搜索）/ 角度子范围 / `timeoutMs` / `greediness` / `subpixel` | `-find-levels` / `-find-angle*` / `-timeout` / `-greediness` / `-subpix` | ③ 速度与精度 |
| `boxMode` / `showContour` / `showPoints` / `showGradients` | `-box` / `-no-contour` / `-show-points` / `-show-grads` | ③ 结果框样式 / ⑤ 界面选项 |
