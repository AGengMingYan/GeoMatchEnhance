## 一、最终结论（深夜更新）

1. **"角度桶多样性配额"启发式：无效且更慢，已删除。**
   data2 全量 36/36 输出与旧版逐位相同，单图 search 从 24 ms 涨到 46 ms。
2. **真正根因不是候选排序，也不是"外观差异无解"**，
   而是**评分语义把图像侧弱梯度点过度惩罚**：
   归一化平面按 `w=min(|grad|/minContrast,1)` 衰减弱点的 dot 后仍计入 mean；
   Halcon 的语义是这些点**不参加评分**（分母同步缩小）。
3. **已实装 `skipWeight` 修复**（默认 0.9）：全部评分路径跳过 `w<w0` 的点。
   实测 **data2 −90° 簇 0/18 → 17/18（Halcon 11/18，反超）**、
   data1 分数 gap 0.33 → 0.07、负样本 max 0.444→0.403。
   完整数据见 `docs/data1-data2四器对比报告.md` 第九节、
   `docs/ShapeMatch-vs-Halcon.md` 第十六节。

## 二、本次排查过程（按顺序，含中间结论与证伪记录）

1. **单图探针**（新增 `SM_PROBE` 支持）看粗层每个角度的分数图峰值，
   以及**真值位置上**的分数：

   `scan_1776334904474_score.jpg`（NCC 真值 640.35,506.61 @ −88.6°），粗层 level-2：

   | 角度 | 真值位置上的粗层分 |
   |---|---|
   | 10.08° | 0.645 |
   | 7.02° | 0.636 |
   | **−90.83°** | **0.482** |
   | **−87.77°** | **0.481** |

   → 正确的大角度位姿在粗层确实**只有 0.48**，而错误朝向能到 0.65。
   （修正：这个 0.48 本身就是"弱幅值点被惩罚"的结果，skip 修复后该图 0.592 检出。）

2. **候选排名**：`uniq` 共 2101 个候选、`keep=48`。真值处正确位姿（−93.9° @ 645,505）
   排在 **uniq#162**（0.585），同位置 7° 的错误位姿排在 #23（0.685）。
   → 全局截断必然丢掉它，但这只是"症状"。

3. **对齐模板对照**：把模板旋转 +90°（与 −90° 簇真实朝向对齐）另建 `±10°` 小角度模型
   `build/_data2p90.shm`（957 点），对 18 张 −90° 图跑一遍，取真值 25px 内的最高分：
   11 张 0.29~0.36（Halcon 0.57~0.68）、7 张两器都无检出。
   ——当时据此判断"正确位姿只能拿 0.3"、删除了启发式。
   **（再修正：当时 rescore 尚未带 skip 语义；skipWidth 实装后全局模型即可检出 17/18，
   "外观差异"只解释剩余 ~0.1 分差。）**

4. **放大对照图**确认：模板（0° 簇）= 单暗孔焊盘；−90° 簇 = 双暗孔 + 斑纹实例。
   这解释了修复前两器分数的 **~0.1 量级差**（0.59 vs 0.58 一致后仍存在的小差距）。

5. **合成贴回 + 逐点 cos 直方图** → 定位到软权重语义 → **skipWeight 实装**
   （详见 data1-data2 报告第九节）。
